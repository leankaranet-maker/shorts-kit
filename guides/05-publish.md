# 5. Deliver and post

## Files

- `out/NN-slug.mp4`: 1080×1920, 30 fps, H.264 CRF 18, AAC, −14 LUFS. One per clip, or `-A` / `-B` when there's a CTA keyword (A for TikTok + YouTube, B for Instagram + Facebook).
- `out/NN-slug.txt` (you write it after the final render), ready to copy-paste:

```
TITLE (≤ 60 characters, in their language, the viewer's problem or a number + the benefit)
...

DESCRIPTION (one line that adds to the title, then 3 hashtags including #shorts)
...

COVER: second X (a frame where they look at the camera, mouth closed)
```

Titles follow the hook's idea but aren't a copy of it.

## Posting

Default: they upload by hand to each app from `out/` (from the laptop, or copy
the files to the phone). Tell them the order you'd post in (strongest first,
one a day) and the best default time for a Greek audience: **19:00 Athens time**.

If they have a scheduling tool connected to Claude (Metricool, Buffer, …),
offer to schedule. **Show the full schedule table (date, time, title, file) and
schedule nothing before they say yes.** Scheduling tools need each video as a
public link (e.g. a Google Drive file shared «Anyone with the link»), not a file
on the laptop. Post to Instagram as a normal Reel, not a trial Reel. TikTok
needs a title.
